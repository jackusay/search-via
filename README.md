**Quickly search Thunderbird messages by email address, domain, or subject — from the context menu.**

## 🚀 Features

- **Right-click context menu** on any email in Thunderbird
- Search messages from the **same sender**
- Search messages from the **same domain** (`@example.com`)
- Search messages with the **same subject**
- Lightweight and privacy-focused — runs entirely within Thunderbird
- No external dependencies or tracking

## 📥 Installation

1. **Download the latest `.xpi` file**  
   *(Releases coming soon — for now, build from source)*

2. **Open Thunderbird** → `Tools` → `Add-ons and Themes`

3. Drag and drop the `.xpi` file or click the gear icon → **Install Add-on From File**

4. Restart Thunderbird

> **Note**: This extension is not yet published on [addons.thunderbird.net](https://addons.thunderbird.net). Install from source or future releases.

## 🎯 Usage

1. Right-click on any message in your inbox or folder
2. Hover over **"Search Via"** in the context menu
3. Choose:
   - **Same Email** – Find all messages from this sender
   - **Same Domain** – Find all messages from `@domain.com`
   - **Same Subject** – Find all messages with identical subject line

Results open in a new tab using Thunderbird’s built-in search.
